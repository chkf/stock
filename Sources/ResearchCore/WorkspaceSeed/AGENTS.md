# 股票研究台手机工作区

这里是有实际行情和账户的 iPhone 工作区。先读「设计/手机开发说明.md」与「设计/workspace.json」。

- 改首页或标签栏，在「设计/页面」调整组件，在 workspace.json 登记新页面。
- 改市场判断，在「设计/策略」编辑独立策略和共用指标。五套默认方案各自计算，保留策略身份。新实验可在「设计/功能」写脚本，配套资料放「输入」。
- 将含唯一 id 和 operation 的「请求.json」原子写到本目录。reload 启用设计，run 执行指定功能，strategy 重算指定策略。App 在前台时处理。读取「输出/请求状态.json」并核对 id，再读研究结果或「输出/市场判断」。
- 「数据」含已确认账户、观察记录和带来源摘要的历史行情。分析时读取需要的资料，对照结果另存。备份整个研究工作区可保留历史、输入、输出和已验证版本。
