# 动态 ETF 目录与本机 JS 正式回测 · 候选版 1

适合测试新版回测底座；不会把你的策略换成内置混合算法，也不会启用 109 只固定池。保留旧工作区、行情、五套策略、含费买单预算和 ledger 3。

**下载与安装：** 附件 `StockResearch-unsigned.ipa` 为 iPhone arm64 未签名包（iOS 16 及以上，0.4.0 / build 5）。请用上个版本相同的签名团队和应用标识签名后覆盖安装，**不要先卸载**。若签名不匹配，请停止安装，不要删除手机数据。此版本不会自动采集全量行情。

**怎么试：** 先确认旧页面、行情和回测仍可打开。测试新模式时，在现有工作区追加契约 2 的 JS 策略，执行 `reload`，挂载已核目录快照后选「本机目录」和该策略，或发送正式 `replay` 请求。只有账簿保存后才回执 `done`；没有合格历史和行动证据不会生成正式结果。包内不附动态池长期真实历史。
