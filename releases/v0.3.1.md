# 回测买单费用预算修复

修复同时买入多只 ETF 时，单笔预算没有包含佣金和滑点、导致现金足够却买不进整手的问题。新预算包含实际费用，拆单分别计算最低佣金；现金不足时按含费需求比例分配，继续遵守整手和不得透支的限制。五套策略的选仓、权重、调仓和保护退出规则保持不变。

**升级后请重新运行回测。** 账簿版本升至3，新旧回测分开保存，旧报告保留，旧检查点不会续接到新版。原有行情、真实账户记录和自定义工作区保留。

本地40项 Python 测试和20项 Swift 核心测试通过。五套策略使用同一份2026-01-19至2026-11-18行情交叉回放，201个交易日、共264笔成交，逐日权益核对到分、逐笔成交与恢复一致。[对账记录](https://github.com/chkf/stock/blob/v0.3.1/verification/fee-budget-v3.json) · [修复说明](https://github.com/chkf/stock/blob/v0.3.1/docs/买单费用预算修复.md)

附件为未签名的 iPhone arm64 IPA，支持 iOS 16.0 及以上，应用版本0.3.1（构建4）。发布流程会先运行核心测试、完成设备归档并校验安装包。覆盖安装请沿用旧版的签名团队与应用标识，以保留手机资料。本次未进行真机验收；跨端对账使用共同输入，不代表用户手机当次466日原始账簿已逐笔核验。
