# 长历史回测与原生日期滚轮

在「市场 → 回填本机历史行情」可以为 28 只 ETF 向前补历史，暂停后可续传。导入已有快照后，在回测页选择「导入快照」或「本机行情」，即可看到各策略满足预热和校验要求的日期范围。点起止日期打开滚轮。遇到缺行情、未核实的分红或折算，覆盖明细会显示受影响的证券、日期和原因。

五套策略已用真实行情在两个区间与原 Python 对账，共 294 笔模拟成交，逐笔一致，每日权益核对到分。随源码提供的样例中，五套策略共同可用的回测区间为 2025-10-22 至 2026-11-17。完整 2010 年代仍有行情缺日和公司行动待核验。[样例、已知差异和导入说明](https://github.com/chkf/stock/blob/v0.3.0/docs/长历史回测.md)

附件为未签名的 iPhone arm64 IPA，支持 iOS 16.0 及以上。覆盖安装请沿用旧版的签名团队和应用标识。GitHub Actions 已通过 17 项核心测试并完成设备归档。本次未运行模拟器或真机验收。[构建记录](https://github.com/chkf/stock/actions/runs/44335429115)
