# 验收执行记录

**尚未使用实体 iPhone 验收。** v0.2 的交付目标是让手机 agent 直接访问「我的 iPhone / 股票研究台 / 研究工作区」，升级时接续旧账户、行情和报告。电脑端已验证从旧目录迁移、工作区启用与回退，以及 200 个交易日的五套策略账簿和 225 笔模拟成交。

**模拟器已验证。** 在 GitHub 的 Mac 上安装并运行 iPhone 17 Pro 模拟器版本。从 App 外改工作区的页面、首个标签、研究脚本和 JSON 输入，再由「请求.json」触发载入与计算。把输入从 14 改到 21，分别读回 42 和 63。结束并重开 App 后再次得到 63。写入错误脚本后收到带原因的失败回执，旧版本仍能算出 63。此流程由同一份可执行程序完成。外部链接唤起涉及系统打开提示，本次通过的流程使用文件请求。[模拟器和 Xcode 验收记录](https://github.com/chkf/stock/actions/runs/44284323481)

电脑上从空库真实联网取得截至 2026-11-17 的 28 只 ETF 原价与公司行动，然后在新的、隔离外部网络的进程中读回已确认的测试账户，重新计算并保存报告。验证同时回放 11-16 至 11-17 的增量更新、坏响应保留旧快照、来源原件损坏拒读。明细见同目录《空库联网对账.json》。
