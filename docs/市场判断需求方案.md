# 股票研究台 · 市场判断与图表

## 手机工作区（更新后的交付要求）

用户选择让手机 agent 在系统「文件」中开发。工作区位于「我的 iPhone / 股票研究台 / 研究工作区」。新版启用文件共享和就地编辑。旧版本的私有资料在首次升级时原位迁入工作区的「数据」目录。首页、底部导航、页面组件、研究功能和五套策略由文件驱动。原生宿主提供界面组件、受限的 JavaScript 解释器、数学库、行情请求及可恢复的账户回测等运行能力。界面中可以应用、验证或回退工作区设计；同一安装包可运行用户后来编写的策略与功能。原稿中要求在系统「文件」隐藏全部资料的验收条款已由此要求取代。

## 用户目标

收盘后打开手机，一眼看清下一交易日当前策略倾向哪些 ETF、各占多少、为什么这样判断。使用该功能只需行情。实际账户和参考份额仍有独立入口。

## 页面与结果

1. 首页默认「动量／协方差／银行，否则四类」。下方可切换跨资产动量、协方差最小波动、四类固定配置、板块独立判断。显示信号日、适用日、市场状态、当前分支、入选证券名称和代码、各自目标及剩余现金。市场页面对照策略给出配置方向，实际买卖份额由用户主动进入账户方案核算。
2. 按选中策略展示完整 28 ETF。入选按策略权重展示，并列权重同名次。动量分数只用于有该分数的策略。保留四类配置、银行条件和板块防守分配各自的含义。过期只展示带日期的历史判断，证据不足、持币和已完成计算都有明确的文字结果。
3. 行情页可以查看 28 ETF 和自选证券的实际历史价格。支持双指缩放、左右移动、查看某日数值和区间切换。自选股本轮先做行情观察，个股买卖规则延后。
4. 回测图在同一起点和口径下展示五套策略的累计净值及回撤。图中日期、曲线来源、交易假设及可用范围必须可查。重放和价格走势分别标注。
5. 主要统计为某策略在该标的从实际建仓到退出、扣费后的完整周期历史命中率，同时给出盈利次数和有效样本数。没有平仓的周期不计入。主要预测目标是本次持有到退出的净盈利概率，须有截至该日可用的训练数据和时间外检验。原版 5／20 日收盘上涨模型作为补充，独立标注。数据不够时展示具体原因，历史命中率不会填到预测栏里。

## 验收场景

主策略首屏显示「离强势还差多少」。按原版当日有完整历史的 A 股 ETF 计算，不把海外、商品、债券计入分母。60 日和 200 日各显示满足「收盘价高于均线且均线较 20 个交易日前上升」的只数、占比、60% 门槛与尚缺只数。两条均满足才进入强势。没有有效样本时显示缺少历史，过期时展示原日期。两条缺口分别列示，证券可能重叠。同步显示弱势时银行分支是否通过。

- 空账户更新行情后直接看到主策略结论；切换方案立即看到自己的路由、名单、权重，不把多套配置加总。
- 指定同一快照，五套策略的市场状态、路由、选中名单、权重与 Python 对账。SLSQP 使用原算法、初值、约束与停机条件。
- 参考当前持仓时另行确认账户。没有账户也能查看全部市场判断和图表。
- 行情滞后显示实际截止日期；不足以计算的概率显示原因与样本数；空目标显示持币。
- 图表能缩放、移动和读数；每条收益曲线可追溯到账簿，普通行情图明确价格口径。
- 更新已有安装时保留私有行情、账户及历史报告。按实际完成的验证记录发布，真机结果单列。
