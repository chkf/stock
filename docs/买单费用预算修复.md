# 买单费用预算修复（v0.3.1）

在 v0.3.0 / 979856a3bcf57013cd630e245848cc97d0cae6ff 上，多标的买单分配预算时，以不含佣金和滑点的成交金额封顶，成交时却要求金额加费用。这会让本来买得起的100份委托始终不能成交，也会让较大委托每次少买一手。

现在每单预算需求包含成交金额和费用；超过每笔100万份上限时，按每笔实际拆单分别计算最低佣金。现金不足时按含费需求比例分配，仍按整手成交、保留剩余委托且禁止透支。卖出先于买入，调仓、退出、行情和公司行动规则不变。日常账户建议原本已预留费用，此次修复的是回测执行。

账簿版本由2升到3，回测输入指纹包含新版本。升级安装后，需要重新运行所选区间回测；旧指纹下的报告文件保留，不把旧检查点续接到新账簿。安装包以 GitHub Releases 上的 v0.3.1 为准。

回归测试在 `Tests/ResearchCoreTests/ReplayFundingTests.swift`，覆盖两个高价国债ETF的100份买单、足额/不足资金、拆单最低佣金、剩余意图、恢复和版本拒续；现有分红、份额折算与交易状态测试继续运行。

桌面对应引擎为 `research/sector_selection_20261114/sector_account_v2.py`。旧 `sector_account.py` 冻结保留，以重现旧报告。`tools/replay_reference.py` 已默认使用新引擎和新输出目录，重复输出会拒绝覆盖。
